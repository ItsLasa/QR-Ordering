Act as a world-class Senior Product Designer, UI/UX Architect, and Frontend Engineer with 10+ years of experience designing premium restaurant technology products.

I have already developed a Restaurant QR Code Ordering System. The functionality is working, but the frontend currently looks AI-generated, generic, and lacks a professional human-designed appearance.

Your task is to TRANSFORM the existing frontend into a premium, production-ready restaurant ordering experience.

### 1. Design Philosophy

The design must feel like it was created by an experienced human product designer, not generated by AI.

Follow these principles:
- Create a clean, intentional, sophisticated visual hierarchy.
- Use realistic spacing and carefully balanced proportions.
- Avoid repetitive layouts and unnecessary UI elements.
- Use typography with a clear personality.
- Make the interface feel warm, welcoming, and suitable for real restaurants.
- Prioritize usability over decorative design.
- Every component must have a clear purpose.

### 2. Remove AI-Generated Design Patterns

Audit the existing UI and remove unnecessary:
- Excessive rounded cards and pill-shaped containers.
- Purple, blue, and multicolor gradients.
- Glassmorphism effects everywhere.
- Excessive drop shadows and glowing borders.
- Unnecessary decorative icons.
- Repetitive card-based layouts.
- Oversized headings and meaningless labels.
- Random animations and hover effects.
- Generic AI-generated dashboard layouts.
- Excessive whitespace and inconsistent spacing.

Do not replace these with another generic template.

### 3. Professional Visual Direction

Create a premium restaurant-inspired design system.

Use:
- Warm neutral backgrounds.
- Deep charcoal or dark brown text.
- One carefully selected accent color.
- Elegant typography combinations.
- Subtle borders instead of excessive shadows.
- Consistent spacing and alignment.
- High-quality food photography.
- Clean, purposeful buttons and controls.

The design should resemble a professionally art-directed restaurant brand.

### 4. Restaurant Customer Ordering Experience

Pay special attention to the customer-facing QR ordering interface.

Improve:
- Restaurant header and branding.
- Food category navigation.
- Food item presentation.
- Food image proportions.
- Product descriptions and prices.
- Add-to-cart interactions.
- Quantity selectors.
- Cart summary.
- Order confirmation.
- Mobile navigation.

The menu should feel like browsing a real restaurant menu, not shopping on a generic e-commerce website.

### 5. Responsive Design

Mobile-first design is essential because customers access the system by scanning QR codes at restaurant tables.

Ensure:
- Excellent experience on 360px–430px mobile screens.
- Easy one-handed navigation.
- Readable typography.
- Proper image proportions.
- Fixed bottom cart summary where appropriate.
- No horizontal scrolling.
- Comfortable touch targets.
- Smooth but subtle interactions.

Desktop and tablet layouts must also remain professional.

### 6. Design Consistency

Create a consistent design system covering:
- Colors.
- Typography.
- Spacing.
- Border radius.
- Buttons.
- Input fields.
- Navigation.
- Food cards.
- Modal dialogs.
- Loading states.
- Empty states.
- Error states.

### 7. Important Development Rules

Before modifying anything:

1. Inspect the entire existing project structure.
2. Identify the current frontend framework and styling system.
3. Review all existing pages and components.
4. Understand the existing application functionality.
5. Identify repetitive and AI-generated visual patterns.
6. Create a redesign plan before implementation.

STRICT RULES:
- Do not rebuild the application from scratch.
- Do not remove existing functionality.
- Do not modify backend APIs, database schemas, authentication, or business logic.
- Do not break existing routes.
- Reuse existing components where appropriate.
- Keep existing integrations working.
- Do not introduce unnecessary dependencies.
- Do not change working functionality just to improve appearance.

### 8. Implementation Process

Work page by page.

First improve the customer-facing ordering experience, then improve the remaining pages and administrative dashboard.

After implementation:
- Check every page.
- Test mobile responsiveness.
- Verify all buttons and interactions.
- Check image loading.
- Fix layout inconsistencies.
- Remove unused styling.
- Ensure the final product looks cohesive.

FINAL EXPECTATION:

I want a premium, realistic, commercially usable restaurant QR ordering system that looks like a product designed by a professional human UI/UX designer.

Do not just make the current UI prettier. Rethink the visual experience while preserving the existing functionality.
